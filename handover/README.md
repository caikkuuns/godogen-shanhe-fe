# 交接区 · 山河剑行

这个目录是**萧炎团队**和 **Grok Bot** 之间的交接点。谁改了东西，就在这里写清楚：改了什么、为什么改、验证结果、下一步。

## 代码在哪

- **仓库**：https://github.com/caikkuuns/godogen-shanhe-fe
- **可见性**：必须是 **Private**。2026-11-26 曾被发现处于公开状态（匿名访问返回 200），已切回私有并核实。**任何人不得把本仓库改成 Public**——要公开先按 `docs/仓库脱敏清单.md` 脱敏。
- **默认分支**：`master`
- **服务器**：地址与路径见本地 `~/server-notes.md`（不入库）。服务器上的 git remote 指向本机裸仓库，不是 GitHub。

## 规矩

1. **改代码走 GitHub**。Grok Bot 直接在仓库上改、开分支、提交、开 PR。不要绕过仓库改服务器工作区，否则两边会打架。
2. **每次交接写一篇说明**，文件名格式：`交接-YYYYMMDD-谁-主题.md`，放进本目录。
3. **写清楚四件事**：
   - 改了什么（文件 + 行号 + 改动内容）
   - 为什么改（对应哪条问题/需求）
   - 怎么验证的（跑了什么测试、看了什么截图、数字是多少）
   - 下一步谁接手（还有哪些没做）
4. **不许写进仓库的东西**：服务器密码、任何令牌、内网 IP、`incoming/` 下的中间产物。
5. **不要动**：`assets/glb/shenyan.glb`（原版）、`assets/glb/opt/shenyan_hero.glb`（建模师手上的当前版本），要改先在本目录写说明。
