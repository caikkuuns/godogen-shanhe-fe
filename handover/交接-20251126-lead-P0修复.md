## 为什么

美术评审 P0-1「白袍灰黑碎三角斑」、P0-2「脸部白色横条」的直接成因是 shader 的 gutter 判定：

```glsl
bool gutter = lum >= 0.18 && lum < 0.62 && chroma < 0.14
    && !skin && !trim && (uv_edge || lum < 0.56);
if (gutter) { c = fill_color; EMISSION = c * 0.85; }
```

`fill_color` 对沈砚是 `(0.86,0.86,0.88)` 冷灰。gutter 本意是补 TripoSR atlas 的岛间空隙，但判据是「按亮度猜」，白袍褶皱暗部（lum<0.56）和冷灰空隙长得一样 → 一起被刷成亮灰 + 自发光。

实测：全图命中 13.6%，UV 岛内命中 16.6%；命中区可视化正好是袍子块边缘一圈 + 褶皱暗部 + 脸上小块。

贴图本身：718 个 UV 岛、79.5% 面积 <50px、UV 覆盖仅 26.51%、空隙是亮度<40 的黑噪点占 40%。所以关掉 gutter 前必须先把空隙填满，否则会露黑斑 —— 这就是第 3 项改动的理由。

## 怎么验证

本机无 Godot，只做了结构校验（GLB buffer 长度自洽、贴图 PNG 合法、节点数一致）。**必须在服务器真渲染**：

```bash
godot --path . -s tools/capture_shenyan_round10.gd
ls captures/kimi_walk_0*.png      # 硬指标 8 帧，目前还是 0 个
```

看三点：

1. 白袍上不再有灰黑碎三角斑（重点看肩、袖、裙摆）
2. 脸部无白色横条，五官完整
3. 袍子暗部保留自然褶皱阴影，不是被涂成一片死灰

若关掉后出现新的黑洞 → 说明某处空隙没填到，把 `gutter_for` 里 `shenyan_hero` 改 `0.5` 折中。
