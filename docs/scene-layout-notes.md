# 《山河剑行》场景构图注释（基于 scene-reference-v2.jpg）

说明：以下比例均为对参考图的**目测归一化估计**（以画面宽 W、高 H 为 1），不代表真实世界尺寸；标"建议"的为构图建议，不是硬性要求。不复制参考图的 PC 键位提示（Q/E/R/G、F12、右侧闪避/防御等列表）和原游戏 HUD。

## 1. 镜头与人物比例
- 俯视约 45~55° 斜俯角，2.5D。
- 主角站立高度 ≈ 0.07~0.08H（含斗笠），宽 ≈ 0.025W。建议手机上不低于 0.08H，保证 360dp 高屏幕上人物约 28dp 以上、可辨认。
- 相对比例（估计）：
  - 门洞（木牌坊）：总高 ≈ 2.2× 人高，通行口宽 ≈ 3× 人宽。
  - 大石：高 ≈ 3~3.5× 人高，占画面 ≈ 0.15W×0.4H。
  - 竹/树丛：冠幅大于人高 5× 以上，作为画面边框。
  - 石像 ≈ 1.3× 人高；木箱 ≈ 0.6× 人高。

## 2. 中心通行区域
- 主路为纵向土路：从门洞（约 x 0.40~0.52，y 0.25~0.45）向下延伸至画面下沿，再向左右分岔（y 0.65~0.80）。
- 建议玩家常驻位置在 x 0.45~0.55、y 0.45~0.60；镜头跟随时保持主角在此区域。
- 通行区（x 0.30~0.70，y 0.30~0.85）内不放大型遮挡物，交互物（箱子、NPC）放在路边缘。

## 3. 前/中/后景
- 后景：上部竹林与山石（y < 0.30），可被路径穿过但不遮挡主角。
- 中景：门洞、大石、石像、木箱，与主角同层，按 y 排序遮挡（y 大者在前）。
- 前景：下方草丛/树影（y > 0.80）与左侧竹丛。建议：主角走到前景物后时前景物半透明（约 40%）或描轮廓，不允许完全遮住主角。
- 建议左右两侧密林只做画框，留出中部约 60%W 的视觉通道。

## 4. 手游 HUD 留白（对应 ui-spec.md）
- 参考图左下血条和右下键位区域正好落在前景草地/树影处，这种"HUD 叠在暗色前景上"的布局可借鉴。
- 保持中心 x 0.25~0.75、y 0.20~0.75 无常驻 HUD。
- 左下摇杆、右下主键/技能放在前景暗区；左上状态、右上菜单放在竹林后景上，均用半透明深色底。
- 镜头建议下移少许，让主角在画面中心略偏上（y≈0.48），给底部 HUD 留出约 0.25H 的前景空间。

## 5. 验收
1. 主角在 360dp 高屏上可辨认（≥ 约 28dp 高）。
2. 中心通行区无遮挡、无常驻 HUD。
3. 前景遮挡时主角仍可见。
4. 不出现参考图中的 PC 按键文字与原游戏 HUD 元素。
