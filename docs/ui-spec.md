# 《山河剑行》横屏触控 UI 布局约定 v2

## 1. 单位约定（关键）
- **设计稿**：1920×1080 设计像素（px），仅用于美术出图与比例；布局用**归一化锚点**（相对安全区的 0~1 坐标 + 边缘偏移），不写死像素。
- **运行时最小值**用真实 dp：典型横屏窗口约 800×360dp（20:9 约 800×360，16:9 约 640×360）。设计 px → dp 换算 ≈ 屏高dp/1080（360dp 高时 1px ≈ 0.33dp）。
- 尺寸取 max(按比例换算值, dp 下限)，并对大屏设上限。
- **安全区**：只用系统实际 inset（WindowInsets：displayCutout + systemBars/手势），另加 8dp 内边距；不设固定大边距。

## 2. 布局（以 800×360dp 为例，坐标在安全区内）
| 元素 | 锚点 | 设计稿 px | 800×360dp 实际 |
|---|---|---|---|
| 头像+血条/内力 | 左上 | 头像 96，血条 300×14 | 头像 36dp，血条 110×5dp（条可细，非触控） |
| 菜单/背包/地图/存档 | 右上横排 | 图标 72，间距 16 | 图标视觉 24dp，热区 44dp，间距 4dp |
| 任务提示 | 左侧，头像下方 | 宽 ≤480 | 宽 ≤170dp，≤2 行，可点折叠 |
| 摇杆/方向键 | 左下，圆心 x=0.13, y=0.72 | 底盘 300，拇指 120 | 底盘 104dp，拇指 44dp；方向键单键 44dp |
| 交互/攻击主键 | 右下，圆心 x=0.88, y=0.74 | 192 | 64dp |
| 技能键 ×3~4 | 主键左上弧形 | 120，间距 24 | 44dp，间距 8dp |
| 对话框 | 底部居中，仅对话时 | 宽 60%，高 300 | 宽 ~460dp，高 ≤100dp |
| 对话立绘 | 对话框侧上方 | 高 ≤60% 屏高 | 高 ≤210dp，半身，说话方亮、另一方压暗 |

- 中央视区：安全区中部约 50% 宽 × 55% 高不放常驻 HUD，保证 2.5D 人物/建筑可见。
- 20:9 加宽部分留给场景；左右 HUD 跟边缘锚点走，不拉伸。

## 3. 触控（真实 dp 下限）
- 可触热区 ≥44dp（推荐 48），主键 ≥56dp；热区可大于可见图标。
- 相邻热区间距 ≥8dp。
- 按下反馈：缩放 0.92 + 高光。

## 4. 中文字号（sp，以 360dp 高窗口为准）
- 对话正文 14~16sp（下限 13），行距 1.4，每行 ≤24 字。
- 任务提示 12~13sp，标题 14sp。
- 按钮/技能名 11~12sp（下限 11）。
- 数值 11sp 等宽。
- 文字加 1dp 描边或半透明底，保证亮暗场景可读。

## 5. 视觉风格
- 深墨半透明底（#141414 @ 55~70%）+ 1dp 细金/铜描边，圆角 ≤6dp。
- 禁止米色大方块按钮、大面积实色铺底、常驻厚卷轴边框。
- 常驻 HUD 总面积 ≤ 屏幕 15%。

## 6. 回合战斗（保留现有玩法，只定布局）
- 探索 HUD 中摇杆隐藏；现有战斗指令按钮放右下，与主键同一区域，按钮 ≥44dp、间距 ≥8dp。
- 角色血条挂头顶，不压脸；不新增功能。

## 7. 验收要点
1. 在 ~800×360dp（20:9）与 ~640×360dp（16:9）上，控件全部位于系统 inset 内，无裁切；未用固定大边距。
2. 中央视区无常驻 HUD，人物与建筑可见。
3. 所有可触热区 ≥44dp、间距 ≥8dp；摇杆底盘约 100dp，不超过屏高 30%。
4. 对话正文 ≥13sp 且清晰；最小字号 ≥11sp。
5. 无米色大方块按钮，风格统一。
6. 对话立绘不遮文字，结束后移除。
