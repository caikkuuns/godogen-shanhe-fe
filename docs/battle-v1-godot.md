# 《山河剑行》战斗 v1（Godot 竖切片）

> 来源：由 `docs/gameplay-spec.md` v2 压缩而来，只改范围，不改核心数值。
> 状态：**设计规则，未实现、未实测**。数值都是设计值，实测后再调。
> 目标：一场单人回合制战斗，玩家能看懂四个动作，能读懂敌人的重击预告，胜负后回到探索。

## 1. 本轮范围
- 只有 1 场战斗：沈砚 1 人对 厉横 1 人（名字取自 story-data.md）。
- 没有站位、格子、移动、随机、暴击和逃跑。
- 林照晚和僧人这一轮不参战。

## 2. 回合流程
1. 进入战斗：载入战斗数据，内力重置为开场值，记录进场快照（生命、药数量）。
2. 我方回合：玩家从四个动作里选 1 个。
3. 结算我方动作。如果敌人生命 ≤ 0，立即胜利，敌人不再行动。
4. 敌方回合：按固定循环执行下一步。
5. 结算敌方动作。如果沈砚生命 ≤ 0，立即失败。
6. 清除守势，回到第 2 步。

**无效动作不算回合**：内力不够时选剑技、药为 0、或满血时用药，按钮直接置灰或弹提示，不扣资源，不推进回合。

## 3. 我方四个动作
| 动作 | 效果 | 资源 |
|---|---|---|
| 普攻 | 倍率 1.0 | 内力 +5 |
| 剑技 | 倍率 1.8 | 内力 −10，内力 < 10 不能用 |
| 守势 | 本回合受到的伤害 ×0.5，向下取整；只管这一回合，不能叠加 | 内力 +8 |
| 回复药 | 生命 +35，不超过上限 | 药 −1 |

内力不超过上限，多出的部分作废。

## 4. 伤害公式
`伤害 = max(1, round(攻击 × 倍率 − 防御))`

守势时，在上面结果的基础上再 `floor(伤害 × 0.5)`。

## 5. 数值（设计值）
| 参数 | 值 |
|---|---|
| 沈砚 生命上限 / 攻击 / 防御 | 100 / 12 / 4 |
| 沈砚 内力上限 / 开场 | 30 / 20 |
| 回复药 初始数量 | 2 |
| 厉横 生命 / 攻击 / 防御 | 100 / 14 / 2 |
| 厉横 普攻倍率 / 重击倍率 | 1.0 / 2.5 |

按公式算出的检查值：
| 情况 | 伤害 |
|---|---|
| 沈砚普攻 | 10 |
| 沈砚剑技 | 20 |
| 厉横普攻 | 10 |
| 厉横蓄力 | 0 |
| 厉横重击 | 31 |
| 厉横重击，沈砚守势 | 15 |

建议所有数值放在一个数据文件或常量表里（比如 `battle_data.gd` 或 `.tres`），方便调。

## 6. 敌人行动与预告
厉横按 `普攻 → 普攻 → 蓄力 → 重击` 循环，固定不随机。

- 蓄力：不造成伤害，只显示预告。战斗日志写“厉横握紧刀柄，正在蓄力！”，敌人头上显示“蓄力”标记。
- 重击：在蓄力之后的下一个敌方回合打出。打完清除“蓄力”标记。
- 预告的作用：让玩家知道下回合该用守势，或者赶在重击前用剑技打死他。

## 7. 胜负与回到探索
- **胜利**：厉横生命 ≤ 0。显示胜利结算，回到探索场景。只设置一个“已胜利”标记，交给剧情流程使用。战斗胜利不等于交付任务。
- **失败**：沈砚生命 ≤ 0。显示“再战 / 返回”。两个选项都把生命和药恢复到进场快照，不给任何胜利奖励。“返回”回到探索，战斗可以重新触发。
- 存档：战斗中不存档。只在战斗外保存胜利标记、药数量等状态。

## 8. 纸面检查（不是实测）
- 读预告打法：在重击回合用守势，大约 8 回合胜利，剩 45 血，不用药。
- 不守硬打：大约 7 回合胜利，剩 29 血。
- 两种打法都能赢；守势多保留 16 血，硬打快 1 回合。这就是取舍。

## 9. 测试点（对应 headless 测试）
1. 伤害值和第 5 节表格一致：10、20、10、0、31、15。
2. 内力 < 10 时剑技无效，资源和回合都不变。
3. 药为 0 或满血时用药无效，资源和回合都不变。
4. 守势只对本回合生效，下回合恢复正常伤害。
5. 敌人行动严格按 普攻、普攻、蓄力、重击 循环。
6. 击杀当回合，敌人不再行动。
7. 失败后生命和药恢复为进场快照，没有胜利标记。
8. 胜利后设置胜利标记，回到探索，不重复发奖励。
